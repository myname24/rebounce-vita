# Credits

- **Thomas Perl (thp)** – the approach this port is built on: running the original
  Nokia N900 ARM binary through a translation layer with shims for libc, GL/X11/EGL,
  PulseAudio and dbus, as demonstrated by **Maemulator**
  (https://thp.io/2023/maemulator/) and his earlier softfp→hardfp work
  (https://thpmaemo.blogspot.com/2021/02/rebounce-softfp-to-hardfp-ldpreload.html).
  This project is an independent Vita implementation inspired by that work, including
  the accelerometer rest-vector/rotation mapping. Please see thp.io for the original.
- **Rovio Mobile Ltd.** – author of Bounce Evolution (N900 technology demo). All game
  code and assets are theirs and are **not** included in this repository.
- **vitaGL** (Rinnegatamante) – OpenGL layer for the Vita.
- **VitaSDK** and the PS Vita homebrew community.
